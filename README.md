# learning-checkpoints · 四检查点学习

一个以中文讲解为主的Agent Skill，用具体问题和必要概念帮助理解陌生知识。四个检查点是明确对象、建立联系、理解解释与做法、检验与使用；可以往返和略过，不要求每次完成四道作业。

当前版本：**v0.2.0**。本版明确学习目标、理解困难诊断、反馈与结束条件，以及改写时的关系保真。首次公开的[v0.1.0原始基线](https://github.com/DrIsDr/learning-checkpoints/releases/tag/v0.1.0)继续保留；说明、许可证与试用材料放在技能目录之外。

## 适合做什么

- 理解陌生概念、论文机制和跨专业背景。
- 用一个具体例子连接概念、做法与适用条件。
- 按需检查理解，区分已经讲过与用户实际表现。
- 辅助组织学习笔记或朗读稿中的概念顺序。

它不自带PDF提取、联网搜索、语音生成或归档程序；这些能力取决于使用它的工具和项目流程。它也不保证事实永远正确或学习效果已经得到验证。提供原文或可靠来源，可以帮助模型核对关键结论。

## 下载与使用

可以从[发布页](https://github.com/DrIsDr/learning-checkpoints/releases)下载对应版本的源码ZIP。解压后，真正需要安装的是`skills/learning-checkpoints`文件夹。

在支持本地技能的Codex中，可选择：

1. 请内置的`$skill-installer`从本仓库安装`skills/learning-checkpoints`，并指定希望使用的版本标签。
2. 手动把该文件夹放到目标项目的`.agents/skills/learning-checkpoints`，或用户级`~/.agents/skills/learning-checkpoints`。已有同名技能时先检查，避免覆盖本地修改或重复安装。

安装后使用`$learning-checkpoints`调用。没有显示时，按客户端提示刷新或重启。路径及发现机制依据[官方技能文档](https://learn.chatgpt.com/docs/build-skills)；客户端版本可能影响安装方式。

其他支持Agent Skills的工具可以使用`SKILL.md`，但安装位置与调用方式以各自说明为准。`agents/openai.yaml`是OpenAI客户端的可选界面信息。尚未逐个验证其他客户端；普通聊天工具可粘贴指令作为提示词试用，但这不等于安装了技能。

此仓库提供源码和本地技能安装方式，未发布到官方插件目录。

## 调用示例

> 请用$learning-checkpoints解释数据库索引。我的基础是会写简单SQL，希望理解它为什么能加快查询，以及为什么不应给每一列都加索引。

> 请用$learning-checkpoints根据我提供的论文，解释研究问题、必要背景、方法和证据边界，生成连贯的中文学习稿。这次只阅读，不安排问答。

> 请用$learning-checkpoints检查我的理解：我认为准确率更高就一定更适合上线。请结合具体条件指出遗漏。

可直接说明自己的目标、已有基础和交付形式，不必先填写固定表格。仅有摘要时，技能应保留材料范围，不把补充解释当成论文全文结论。

## 独立使用与边界

技能提到的材料处理规范指用户或项目已有的规范，并非本仓库隐藏的必需文件。没有配套规范时，仍可按当前请求直接提供解释，不自动建立归档流程。仓库不包含个人学习材料、聊天记录、模型凭据或机器路径，也不依赖某个私人项目。

四检查点是一种实用的讲解组织方式，不是知识高低层级的权威分类，也未作为一个完整组合开展学习效果实验。一次答对不能证明长期掌握；只读文本也不能验证真实音频听感。
