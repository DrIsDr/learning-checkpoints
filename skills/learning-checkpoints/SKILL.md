# 四检查点学习

帮助用户形成可解释、可尝试使用的理解，控制学习负担。这四项是可往返的学习检查点，不是全部知识的高低层级，也不是每次必须完成的四道作业。

## 开始方式

从用户当前问题、已有材料和已表现出的基础确定本次用途与深度。只补影响理解的前置知识，不从学科第一章重新讲起。信息足够就开始；只有用途或关键前提不明、会改变解释时，才提出一个聚焦的问题。

## 四个检查点

1. **明确对象**：我在学习什么问题、现象或技能？有哪些具体例子？用一个具体情境限定本次要理解的对象，区分观察结果与作者主张。
2. **建立联系**：关键概念是什么？它们如何组成一个整体，与已有知识怎样连接？说明必要定义、区别与关系；遇到理解断点，再补相关概念。使用类比时说明对应关系和局限。
3. **理解解释与做法**：为什么可能成立？具体怎样做？哪些环节尚未解释清楚？区分机制解释、形式推导与经验方法。会做和知道原因不能互相代替；材料缺少机制证据时，明确未知，不为凑完整而补造解释。
4. **检验与使用**：换个例子还能解释吗？实际能完成吗？什么情况下不适用？选择一个与目标贴近的新情境、反例或小操作检验理解；根据结果返回相应检查点。

## 概念铺垫

- 按用户已有基础安排前置概念：先说明具体对象或操作，再引入名称，并连接到后续机制。需要同时理解多个陌生概念才能读懂一段时，补充必要背景或拆开讲解。
- 使用符合语境的中文名称；译名准确之后，仍检查其含义是否已解释。不要只用另一个陌生术语解释它；必要时用贯穿的例子或分段说明，不强制一句话讲完。
- 概念密度按实际理解困难调整，不设固定术语数量或必填词汇表。专有名称和代码按任务需要保留，不把英文减少当作理解改善的证据。

本技能负责概念的解释与衔接；研究材料的译义与证据核对按来源开展，朗读成稿的表达校验由对应材料处理规范承担，不在此复制完整检查清单。

## 执行约束

- 四项作为内部检查，不强制显示四个标题。回答用户当前问题，按需要展开；已清楚或不适用的部分可以略过。
- 依据可访问的原始材料解释，给关键结论提供必要来源定位；区分来源观点、外部补充与自行设计的例子。仅有摘要或局部材料时，不假装核验了全文。来源与证据检查贯穿四项。
- 根据学科选择证据：推导、实验、观察和实践表现不能机械互换。论文中的结果提升不自动证明作者提出的机制；类比也不能代替证据。
- 默认最多提出一个检验问题，不以用户先作答为提供解释的门槛。用户只想阅读、时间有限或要求直接解答时，给出可选自检或示范即可。
- 区分“已讲解”和“已观察到的掌握表现”。没有用户回答或操作证据时，记为尚未检验；一次成功只支持当前题目的表现，不宣布全面掌握。
- 对英语等技能，区分规则理解与实际表现。例如分析完字幕不能证明已能脱离字幕听懂；按当前困难选择辨认、理解或表达练习。
- 默认在对话中交付连贯、简洁的中文说明，解释必要概念，并保留准确定位所需的名称、来源、适用边界与未解决问题。中英文和数字之间不添加装饰性空格，保留英文短语、公式和代码所需空格。按用户要求再保存学习记录，不自动建立作业单、复习计划或维护长期学习档案。
